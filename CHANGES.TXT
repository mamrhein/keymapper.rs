   0.?.?  Add short, intuitive aliases to commands, subcommands and arguments.
          appnames now marks the currently active application in its list.

   0.4.1  Security (control socket & access control):
           - Peer UID verification: the macOS virtkbdd IPC client now calls
             getpeereid(2) to confirm the peer is root before sending key-
             strokes, providing mutual authentication on the IPC channel.
           - Log-level privilege escalation prevention: SET-LOG-LEVEL to
             debug/trace is refused when the peer UID is root and the daemon is
             not running as root.
           - Per-UID rate limiting: a sliding-window RateLimiter (10 connec-
             tions/uid/second) is applied in both the Unix and Windows accept
             loops to prevent flooding of the single-threaded control socket.
          Security (filesystem & config integrity):
           - Atomic config writes: config files are now written via a temp-file
             + rename pattern using O_NOFOLLOW | O_EXCL and mode 0600, preven-
             ting symlink attacks, partial-write corruption, and TOCTOU races.
           - World-readable config rejection: non-root-owned config files with
             world-read permissions are now rejected; all config files are
             created with mode 0600.
           - Parent-chain verification: verify_parent_chain_for_create pre-
             checks directory creation paths before create_dir_all to prevent
             privilege escalation via crafted parent directories.
          Security (log injection & information disclosure):
           - Path interpolation in log statements switched to Debug format to
             prevent log injection via paths containing control characters.
           - Panic backtrace logging demoted to debug level so stack traces are
             not emitted at info/warn levels.
           - Memory ordering for log-level reads corrected from Relaxed to
             SeqCst to ensure visibility across threads.

   0.4.0  Key names and mappings
           - Fixed misassigned key IDs: BracketRight/Backslash and Period/Slash.
           - New control keys: Insert, PrintScreen, ScrollLock, Pause, and Menu,
             with aliases Ins, PrtSc/SysRq, Scroll, Break, and ContextMenu/
             Application.
           - NumpadClear renamed to NumLock with the correct usage ID (0x53);
             NumpadClear still works as an alias.
           - IsoHash removed (its evdev code 99 collided with PrintScreen).
             Note: any config using IsoHash will no longer resolve.
          Behavior
           - Config warnings on hot-reload: a bad edit that hot-reloads is now
             logged at warn level instead of being applied in silence.
             Loading still proceeds on diagnostics.
           - Keyboard enumeration no longer errors when empty.
             The macOS "System Keyboard" placeholder fallback was removed.
             keymapperd logs empty or failed enumerations at error level.
           - Windows device-filter fallback: when a key press can't be matched
             to a raw input event, keyboard filters are now skipped, so
             device-filtered rules fire (as they would for any keyboard) rather
             than not firing at all.
          Security (Windows):
           - Named-pipe DACL actually applied: the control pipe's ACL is now
             correctly restricting the pipe to the current user.

   0.3.2  Fixed Windows installer script.

   0.3.1  Fixed focused-app detection on Linux when started by systemd.
          serde_yaml (deprecated) replaced with serde_saphyr.
          E2E key injector extracted into a dev-only test-util crate.
          E2E tests now require an explicit env var to run locally.

   0.3.0  Added logging through the log facade with ftlog.
          E2e tests: Replaced reader-based with log-based verification.
          Fixed macOS echo re-mapping.
          Fixed stale kernel events on device grab on Linux.

   0.2.3  Migrate winget manifests to multi-file format.
          Migrate Windows installer to Inno Setup 7.

   0.2.2  Add Homebrew cask for precompiled binaries.
          Add Linux binary installer script.
          Add Windows installer and winget distribution.

   0.2.1  Remove Karabiner cask dependency from formula.

   0.2.0  New features:
           - Cross-platform **active app detection**: macOS via objc2, Linux via
             Wayland toplevel-info / X11 (x11rb) / sysinfo, Windows via
             `get_active_app_name`.
           - Keyboard enumeration and filtering: new `keyboards` CLI command,
             cross-platform device listing with port type, keyboard specifiers
             in config and rule groups, compiled into the mapping cache.
           - HID usage unification: `HidUsage` and evdev codes now generated
             from a single table (`common/hid_usage.rs`).
           - Daemon management: `keymapperd` now managed via systemd (Linux)
             and launchd (macOS).
          Platform architecture overhaul
           - Windows app identity (breaking): `apps` entries are now the main
             executable file name of the window-owning process and app-name
             matching is now case-insensitive.
           - Windows `appnames` no longer lists processes whose visible
             top-level windows all have zero area.
          Bug fixes:
           - macOS: the root daemon now resolves the configuration from the
             home directory of the user currently at the console, instead of
             looking only in /var/root.
